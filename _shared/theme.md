# Theme - Navy design tokens

Scraped with Firecrawl from navy-astro.pages.dev (Lexington Themes "Navy"); only tokens and visual language are reused, in a non-commercial demo. Implemented in `app/ui/theme.py`.

| Token | Value |
|---|---|
| Background | `#FAFBFF` |
| Ink (text, accent) | `#111428` |
| Muted text | `#585D6F` |
| Surface | `#EAEEFC` |
| Primary button | `#DBDFFF` on `#111428` text |
| Font | Switzer (Fontshare), 400–700 |
| Sizes | h1 48 px, h2 36 px, 8 px spacing base |
| Shape | square corners (0 radius), no shadows, 1 px hairlines |
| Voice | `/// Section` eyebrows; italic emphasis inside headings ("plan is *wrong*") |
| Pattern | timeline rows (time · state · who) reused for the revision trace |
